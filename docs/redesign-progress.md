### Воспроизведение проверки

Из `student-platform-frontend`: `npm run build`.

Из корня проекта: `.venv\Scripts\python.exe student-platform-frontend/tests/workstation_browser.py`.

Требуются зависимости Django из проекта, Python Playwright и установленный Chrome. В этой среде Playwright загружен только в `.runlogs/browser-test-deps`; для Python 3.12 выбран совместимый greenlet. Сценарий создаёт временную SQLite БД и удаляет её по завершении. Вывод и снимки: `.runlogs/workstation-review/report.json`, `teacher-1440.png`, `teacher-390.png`, `student-1440.png`, `student-390.png`.

Rich-text проверена существующим `tests/rich_text_browser.py`, запущенным через `.runlogs/run-security-check.py` для подключения локальных тестовых зависимостей. Изменений API и рабочей БД не выполнялось.
