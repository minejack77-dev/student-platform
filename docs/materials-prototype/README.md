# Прототип добавления материалов

Режим Operate, существующее направление 02 «Рабочая станция». Пользователь согласовал прототип сценария, а не замену рабочего приложения.

## Что можно попробовать

1. Открыть библиотеку тестов, найти тест по названию/теме или предмету.
2. Создать тест, указав название и предмет. Тема, учебник и раздел необязательны.
3. Добавить вопрос с одним/несколькими ответами или сопоставлением; отметить правильный ответ.
4. Сохранить черновик и обновить страницу. Посмотреть выбранный вопрос глазами студента.
5. Посмотреть пример импорта двух вопросов и добавить их в тест.
6. Назначить заполненный тест группе на выбранную дату; проверить итоговое подтверждение.

## Границы

Данные примеров и изменения хранятся в localStorage этого браузера. Серверный API, реальное назначение, отправка уведомлений и чтение пользовательского Excel не подключены. Импорт явно обозначен как пример. Изображения, rich text, ограничения прав и выбор количества случайных вопросов остаются задачами внедрения, а не обещаниями прототипа. Новая система организации материалов ещё не мигрирует существующие данные.

HTML задаёт оболочку, CSS наследует палитру/типографику текущего DESIGN.md, app.js управляет переходами, формами и локальным состоянием. Файлы не требуют сборки или зависимостей.

Сверка с `DESIGN.md`: сохранены тёмная навигация, светлое рабочее поле, белые панели, основной синий акцент, системный шрифт и базовый текст 14px/1.5. Размеры заголовков и подписей заданы локально для прототипа; это расширение workstation 02, а не новая визуальная система. `DESIGN.md` и `.impeccable/design.json` оставлены без изменений.

Локальный адрес: http://127.0.0.1:8002/ . Запуск из корня проекта: `.venv\Scripts\python.exe .runlogs/materials_prototype_server.py`.

## Проверка

2026-10-07: браузерный сценарий `.runlogs/check_materials_prototype.py` прошёл 16 проверок компоновки (4 экрана × 320/390/768/1440) и 8 функциональных сценариев; ошибок JavaScript нет. Проверены поиск/пустой результат, создание, валидация, сохранение/refresh, предпросмотр/Escape/фокус, пример импорта, назначение и повторное назначение. Восемь снимков и report.json находятся в `.runlogs/materials-prototype-review/`.

Независимое ревью: **ship в пределах трёх исходных замечаний**. После двух проходов исправлений закрыты фокус после замены DOM, обход проверки назначения через историю (включая повторный переход после исправления вопроса) и ложное подтверждение сохранения при отказе localStorage. Все три регрессии дополнительно прошли браузерный сценарий. Это generic review по инструкциям Impeccable; движок не запускался. Проверка на реальном телефоне и ручное прослушивание скринридером не выполнялись.

Дополнительно прошли три регрессионных сценария после замечаний ревью: возврат браузером к назначению повторно проверяет незаполненный вопрос; добавление и удаление варианта ответа сохраняют предсказуемый фокус; при отказе localStorage новый тест остаётся помеченным как несохранённый до успешного повторного сохранения. Эти проверки находятся в `.runlogs/check_materials_prototype.py`; `report.json` перечисляет восемь основных сценариев, а три регрессии отражены в итоговой строке запуска. Их прохождение не заменяет итоговый вердикт независимого ревью.

## После оценки прототипа

Внедрять сначала библиотеку тестов и создание в Vue, затем редактор с существующими Question/Task API, затем назначение через GroupTopicSchedule. В отдельном решении согласовать создание или выбор служебных учебника/раздела для теста без указанного расположения. Существующие материалы и API-контракты сохранять до проверки миграции.
