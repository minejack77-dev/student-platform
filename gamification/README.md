## Интерактивная презентация

**[Открыть demo.html](demo.html)** — автономная визуальная демонстрация, добавленная 01.10.2026. Откройте файл двойным щелчком в браузере; сервер и интернет не нужны. Стили, схемы, иконки и сценарии встроены в один файл.

- Вкладка A: симулятор сдачи с разными результатами, начислением XP, повышением уровня и открытием бейджей. Повторная отправка не удваивает награду.
- Вкладка B: карта учебных целей, тренировка и подтверждение результата повторной проверкой.
- Вкладка C: интерактивный расчёт общей цели с равным весом каждого участника.
- Вкладка D: выбор оформления и демонстрация открытия коллекции.
- Ниже: макет аналитики преподавателя, схема учебного цикла, правила наград, сравнение направлений, план пилота и источники.

Все данные в HTML вымышлены. Состояние хранится только в памяти страницы и сбрасывается при обновлении; к API платформы файл не подключён. Кнопка «Печать / PDF» показывает все четыре варианта для печати. Внешние ссылки на исследования требуют интернета, а ссылки на Markdown-документы — соседних файлов отчёта; сама демонстрация от них не зависит.

Проверено в headless Chrome: сценарии начисления и повторов, достижения, карта, командный расчёт, коллекции, клавиатурное управление вкладками и диалогом, печатный режим. На ширинах 320, 390, 768 и 1440 px нет горизонтального переполнения страницы. При открытии и работе демонстрации — 0 внешних HTTP-запросов и 0 ошибок JavaScript.

Это исследование и предложение к реализации. Код приложения, база данных и настройки сервера не изменялись. Оценки сроков предварительные; фактическая статистика использования, интервью и проверка production в эту работу не входили.
